## 📋 About the Project

A modern, fully responsive landing page for **Kaniwar Motor Bilverkstad** — a car repair shop located in Tomelilla, Sweden. The site showcases the workshop's services, customer reviews, contact information, and opening hours. Built with no frameworks or dependencies — pure HTML, CSS, and JavaScript.

---

## 🚀 Features

- 📱 **Responsive design** — optimised for all screen sizes (480px, 768px, 900px+)
- ⭐ **Review slider** with auto-scroll and navigation dots
- 🔍 **SEO optimised** — meta tags, Open Graph, Twitter Card, canonical URL
- 🏢 **Schema.org LocalBusiness** markup (AutoRepair type) for rich search results
- 🎞️ **Smooth scroll animations** using IntersectionObserver
- 🍔 **Mobile hamburger menu** that pushes content down (no overlay)
